## 一、神经渲染是什么 [D]

> **来源**: C01-C09 案例 + 4 篇 SIGGRAPH 论文 + NVIDIA NRD 4.0 文档

**神经渲染 (Neural Rendering) = 在渲染管线某个或多个环节用神经网络替代或增强传统算法**。UE5 神经渲染 8 个 C 编号案例按渲染管线阶段分:

| C 编号 | 神经渲染环节 | 网络架构 | 推理位置 | 性能预算 |
|--------|--------------|----------|----------|----------|
| **C01 NeuralPBR** | 材质 PBR 参数化 | U-Net (image-to-image) | **离线** + 烘焙 .dds | **0ms 运行时** (烘焙后) |
| **C02 NeuralGGX** | BRDF 拟合 | MLP 5→64→64→64→3 | **实时 shader** | **0.3 ms/pixel** (传统 GGX 0.05 ms, 6x 慢) |
| **C07 DLSS** | 神经超分 + 时域重建 | CNN (5×5 邻域) | **实时后处理** | **0.5 ms** (TAA 8 帧 1.5 ms, 节省 67%) |
| **C08 RT Denoiser** | Monte Carlo 降噪 | 多通道 CNN (5×5) | **实时后处理** | **0.5-1 spp** 即可达 64+ spp 视觉 |
| **C09 NRC** | GI 辐射缓存 | 8 层 × 64 dim MLP | **每帧 fine-tune** | **150 KB MLP** vs 50 MB voxel atlas (1/333) |
| **C17 PFNN/MANN** | 角色 locomotion | Phase-Functioned NN | **实时动画** | 角色动画帧 (跟渲染性能关系弱) |
| **C18 Text-to-3D** | 资产生成 | 神经 SDF | **离线生成** | 离线 (运行时不消耗) |
| **C19 Muscle Deformation** | 肌肉形变 | MLP | **实时 skinning** | 跟 mesh 顶点数线性相关 |

> **关键观察**:
> 1. **C01 + C18 是离线范式** — 训练/生成后烘焙, 运行时 0 开销
> 2. **C02 + C07 + C08 + C09 + C19 是实时范式** — 推理在帧内完成, 性能影响 GPU 帧时间
> 3. **C17 是动画范式** — 性能影响 CPU/GPU 动画, 跟渲染性能弱相关
> 4. **C07 + C08 是 GPU 性能正向优化** — DLSS 节省 67% GPU, RT Denoiser 节省 99% RT 成本
> 5. **C02 + C09 是 GPU 性能权衡** — NeuralGGX 比传统 GGX 慢 6x, NRC 推理成本 vs 节省 voxel 显存

## 二、神经渲染 5 大范式 [D]

> **来源**: C01-C09 案例交叉 + 4 篇 SIGGRAPH 论文 (Aittala 2015 / Kuznetsov 2021 / Rainer 2023 / Schied 2017)

### 2.1 离线烘焙范式 (C01 NeuralPBR + C18 Text-to-3D)

```
训练/生成 (数小时,RTX 4090 / A100)
  ↓
烘焙到 .dds / .uasset (1 次性)
  ↓
运行时 0ms 开销
```

> **关键事实** (C01 §效果对比):
> - 8 张 texture × 2K = **16 MB / 材质** → **神经网络 1×1 Conv 直接重建**, **省 90% 显存**
> - 传统 PBR 美术流程 3-6h/材质 → 神经 1s 推理

**day-job 落地**: 离线工具描述 + RAG 索引 — "asset pipeline: 神经推理 → 烘焙 → 0ms 运行时"

### 2.2 实时推理范式 (C02 NeuralGGX)

```
训练 (1M 样本,RTX 4090 单卡 1h)
  ↓
MLP 权重 < 100 KB
  ↓
实时 shader 替换传统 BRDF
  ↓
0.3 ms/pixel (传统 GGX 0.05 ms,**6x 慢**)
```

> **关键事实** (C02 §效果对比):
> - 5 维输入 [NdotH, NdotV, NdotL, roughness, metallic] → 3 维输出 [BRDF.rgb]
> - FP16 推理, **比 FP32 快 2x**, BRDF 对绝对精度不敏感
> - **latent space 扩展**: 加 8 维 latent code, 1 个 MLP 表示 N 个材质, 运行时 lerp latent 换材质

**day-job 落地**: "BRDF.NeuralEval(roughness, metallic, NdotH, NdotV, NdotL)" 工具描述

### 2.3 神经超分范式 (C07 DLSS)

```
1080p 渲染 (2.1M pixels)
  ↓
CNN 学习超分 kernel (Conv 1×1)
  ↓
时域历史融合 (5×5 邻域 × 4 channel = 100 features)
  ↓
4K 输出 (8.3M pixels)
  ↓
DLSS 0.5 ms (TAA 1.5 ms, **节省 67%**)
```

> **关键事实** (C07 §效果对比):
> - **4× 像素开销** (2560×1440 → 640×360)
> - 1×1 Conv 极致轻量, **网络权重 < 1 MB**
> - **1 帧延迟** vs TAA **8 帧延迟**
> - NVIDIA Tensor Core 加速, RTX 卡上推理 < 1 ms

**day-job 落地**: "DLSS.Mode = {Off, Performance, Balanced, Quality, UltraQuality}" 工具描述 + 调参 SOP

### 2.4 神经降噪范式 (C08 RT Denoiser NRD)

```
RT 1 spp 输入 (color + depth + normal + motion 4 通道)
  ↓
Stage 1: Pre-pass (切线空间 + visibility)
  ↓
Stage 2: Spatial Filter (5×5 双边 + variance)
  ↓
Stage 3: Temporal Blend (reproject + 网络权重)
  ↓
Stage 4: Neural Refinement (1×1 Conv 学 history 权重)
  ↓
最终 64+ spp 视觉
```

> **关键事实** (C08 §效果对比):
> - **0.5-1 spp/frame** 即可达到 64+ spp 视觉 (16 spp 8ms → 1 spp 0.5ms, **节省 16x**)
> - **多通道联合**: color + depth + normal + motion, **比单 color 通道信息丰富**
> - **时域权重靠网络输出**: 传统 TAA 用固定 luminance clamp, **NRD 用 1×1 Conv 学"该信 history 多少"**
> - **firefly 检测**: 网络专门学处理高光 / 镜面反射区的 outlier

**day-job 落地**: "RT Denoiser.Mode = {Off, NRD, OIDN, SVGF}" 工具描述 + 4 阶段调参

### 2.5 神经缓存范式 (C09 NRC)

```
屏幕空间采 8K sample position (0.1 ms / frame)
  ↓
1 spp path trace 拿 ground truth (0.3 ms / frame)
  ↓
Adam 优化 MLP (8 layer × 64 dim, ~33K params = 132 KB)
  ↓
运行时查询: (pos, dir) → MLP → RGB radiance (0.05 ms / query)
```

> **关键事实** (C09 §效果对比):
> - **150 KB MLP** 替代 **50 MB voxel atlas** (1/333 显存压缩)
> - **8 layer × 64 dim** + 16 frequency encoding (NeRF 风格) = 192 features 输入
> - **多次弹射隐式编码在 MLP 权重里** (Lumen 需 8-16 spp Final Gather 收敛)
> - **MLP 实时更新** (每帧 fine-tune 几百个 sample) — 动态光源无须重 bake

**day-job 落地**: "NRC.Train(samples) / NRC.Query(pos, dir) → radiance" 工具描述

## 三、神经渲染 5 大性能维度对比 [D]

> **来源**: C01-C09 §效果对比 + 4 篇 SIGGRAPH 论文

| 维度 | C01 NeuralPBR | C02 NeuralGGX | C07 DLSS | C08 NRD | C09 NRC |
|------|---------------|---------------|----------|---------|---------|
| **推理位置** | 离线 | 实时 shader | 实时后处理 | 实时后处理 | 实时 + 每帧 fine-tune |
| **运行时开销** | **0 ms** (烘焙) | 0.3 ms/pixel | **0.5 ms** (省 67%) | **0.5-1 spp** | 0.05 ms/query + 0.4 ms/frame fine-tune |
| **网络权重** | 1×1 Conv (小) | MLP < 100 KB | < 1 MB (1×1 Conv) | vendor 闭源 (10-30 MB) | **132 KB** (8×64 MLP) |
| **显存节省/开销** | **-90%** (16 MB → 0) | +1 KB | -67% (4× 像素) | -16x (16 spp → 1 spp) | **1/333** (50 MB → 150 KB) |
| **视觉提升** | +5% (学习 GT) | **+4%** (99% vs 95%) | +5-10% (无拖影) | +20% (高光/反射修复) | +10% (大场景 GI) |
| **平台要求** | 离线 (无要求) | SM6+ | RTX (DLSS) / SM6 (XeSS) | RTX 优先 (NRD) | SM6+ |
| **Fallback** | 传统 PBR | 传统 GGX | FSR1 (无 AI) | SVGF (无 AI) | Lumen Surface Cache |

> **关键观察**:
> 1. **C07 DLSS + C08 NRD 是 GPU 性能正向优化** (节省 67% / 16x)
> 2. **C01 + C09 是显存正向优化** (省 90% / 1/333)
> 3. **C02 NeuralGGX 是 GPU 性能负向** (6x 慢, 但视觉 +4%)
> 4. **C01 + C18 是离线范式**, 运行时 0 开销, **永远是 day-job 默认选**
> 5. **C17 + C19 是动画范式**, 跟渲染性能关系弱

## 四、神经渲染 vs 传统渲染 决策矩阵 [D]

> **来源**: C01-C09 §效果对比 + day-job 落地

| 场景 | 传统方案 | 神经方案 | 神经收益 | 决策建议 |
|------|----------|----------|----------|----------|
| **离线美术资产生成** | Substance Designer 3-6h/材质 | NeuralPBR 1s 推理 | **节省 90% 显存** | **必用** (离线 0 开销) |
| **BRDF 复杂材质 (金属漆/皮肤)** | 4 层 BRDF 叠加 + 10+ uniform | MLP 1 forward | 视觉 +4% | **看场景** (6x GPU 慢) |
| **4K 60fps 单卡** | 原生 4K 跑不动 | DLSS 0.5 ms | **节省 67% GPU** | **必用** (RTX) / FSR 替代 |
| **RT 光追反射/GI** | 16 spp 8 ms (不可实时) | NRD 1 spp 0.5 ms | **节省 16x** | **必用** (RTX 优先) |
| **大世界 GI (10km²+)** | Lumen 5 GB VRAM 爆炸 | NRC 150 KB MLP | **1/333 显存** | **大世界必用** |
| **角色 locomotion** | State Machine + IK | PFNN/MANN | 平滑度提升 | **看项目** (动画师偏好) |
| **角色形变 (肌肉)** | 骨骼驱动 + 蒙皮 | MLP 形变 | 物理感提升 | **看美术预算** |
| **Text-to-3D 资产** | 手动建模 | 神经 SDF | 生成速度 +100x | **快速迭代** (离线) |

## 五、神经渲染 5 大调参策略 (统一心智模型)

> **声明**: 全部基于 C01-C09 案例 + 4 篇 SIGGRAPH 论文 + NVIDIA NRD 4.0 文档 + UE 5.4 源码, 不主张"自己项目能省 X%" — 必须 Profile。

### 5.1 推理位置选择 (离线 vs 实时)

```
决策树:
  资产类型是 PBR 材质 / 3D mesh?
    └─ 是 → 离线烘焙范式 (C01 / C18), 运行时 0 开销
  资产类型是 BRDF 复杂材质?
    └─ 是 → 实时推理范式 (C02), 注意 6x GPU 慢
  资产类型是后处理 (超分 / 降噪)?
    └─ 是 → 实时推理范式 (C07 / C08), GPU 性能正向
  资产类型是 GI / 场景缓存?
    └─ 是 → 神经缓存范式 (C09), 显存节省
  资产类型是角色动画 / 形变?
    └─ 是 → 神经动画范式 (C17 / C19), 跟动画师协作
```

### 5.2 网络架构选型 (U-Net / MLP / CNN)

| 任务 | 网络 | 原因 |
|------|------|------|
| **Image-to-image** (C01 材质) | **U-Net** (encoder + bottleneck + decoder + skip) | 学全局语义 + 局部细节, Normal map 不模糊 |
| **Black-box 拟合** (C02 BRDF) | **MLP** (5-10 层 × 64 dim) | universal function approximator, 几十参数就够 |
| **Spatial filter** (C07 DLSS / C08 NRD) | **CNN 1×1 / 5×5** | 权重共享 + 多尺度, vendor 加速友好 |
| **Function 查询** (C09 NRC) | **MLP + Frequency Encoding** | 6 维输入, NeRF 风格高频细节 |

### 5.3 推理精度选择 (FP32 / FP16 / INT8)

| 精度 | 性能 | 精度损失 | 适用 |
|------|------|----------|------|
| **FP32** | 基线 | 0 | 训练 / 调试 |
| **FP16** | **2x 快** | BRDF / 材质可接受 (< 1%) | **C02 BRDF / C07 DLSS / C08 NRD** |
| **INT8** | **4x 快** | 1-3% | C09 NRC (已有论文) / 移动端 |
| **Mixed** | 灵活 | - | 训练 FP32 + 推理 FP16 |

> **关键事实** (C02 §落地路径):
> "**FP16 比 FP32 快 2x, BRDF 对绝对精度不敏感**" — 实时推理必选 FP16

### 5.4 网络权重压缩 (剪枝 / 蒸馏 / 量化)

| 阶段 | 方法 | 节省 |
|------|------|------|
| **训练后** | 剪枝 (prune < 5% 权重) | -30% 权重 |
| **训练后** | 蒸馏 (大模型指导小模型) | -50% 权重 |
| **训练时** | 量化感知训练 (QAT) | -75% 权重 (FP32 → INT8) |
| **运行时** | 动态量化 | -40% 推理时间 |

### 5.5 Fallback 策略 (平台降级)

| 主方案 | 平台要求 | Fallback |
|--------|----------|----------|
| **C01 NeuralPBR** | 离线 (无要求) | 传统 PBR (Substance) |
| **C02 NeuralGGX** | SM6+ | 传统 GGX (SM5/移动端) |
| **C07 DLSS** | RTX (NVIDIA) | **XeSS** (Intel) / **FSR3** (AMD, 无 AI) |
| **C08 NRD** | RTX 优先 | **OIDN** (Intel, CPU 慢) / **SVGF** (无 AI) |
| **C09 NRC** | SM6+ | **Lumen Surface Cache** (传统) |

> **关键事实** (C07 §落地路径):
> "FSR3 = AMD, **无 (纯算法)**, 中 (无 AI), 全平台" — AMD/移动端 fallback

## 六、跨案例性能 Profile 黄金路径

### 6.1 神经渲染 Profile 4 步

```text
Step 1: 确认推理位置
  - 离线 (C01/C18)? → 0ms 运行时, 无需 profile
  - 实时 (C02/C07/C08/C09/C19)? → ProfileGPU 找神经推理通道
Step 2: 量推理成本
  - 网络权重 (网络参数 × 4 字节 FP32 / 2 字节 FP16 / 1 字节 INT8)
  - 推理时间 (单次 forward / pixel)
  - 显存 (网络权重 + 激活值)
Step 3: 视觉评估
  - SSIM / PSNR vs ground truth
  - perceptual quality (玩家感受)
Step 4: 优化 (按 5.3-5.4 调参)
```

### 6.2 跨案例性能调参 4 类

| 类型 | 调参 | 适用 |
|------|------|------|
| **推理精度** | FP32 → FP16 → INT8 | 全部 5 案例 |
| **网络压缩** | 剪枝 / 蒸馏 / 量化 | C02 / C09 (网络权重敏感) |
| **Fallback** | DLSS → FSR3 / NRD → SVGF | C07 / C08 |
| **离线化** | 实时 → 烘焙 | C01 / C02 (材质可烘焙, BRDF 难) |
