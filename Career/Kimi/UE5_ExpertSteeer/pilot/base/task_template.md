# 任务模板

## 元信息

- **id**: `<domain>_<n>_<slug>`（如 `physics_01_impulse`）
- **域**: physics / rendering / fx
- **目标模型尺寸**: 0.8B / 2B / 4B（按粒度选）
- **UE C++ 形态**（Stage 1 迁移目标）: 说明此任务在真实 UE 工程中的对应类/函数形态

## 任务描述（prompt，中文）

> 给模型的完整指令：背景、输入、期望输出、约束（如单位 cm、容差、不可用哪些 API）。

## 输入规格

- 函数签名（pilot 用 Python，注明 UE C++ 对应签名）

## Golden 解

- 工程化参考实现（含注释），是模型学习的"目标写法"

## Hidden tests

- 输入/输出对 + 数值容差（用 `FMath::IsNearlyEqual` 级别容差 KINDA_SMALL_NUMBER=1e-4）

## Judge rubric（L4 维度，每维 0-10）

| 维度 | 说明 | 权重 |
|---|---|---|
| 正确性 | 逻辑正确、边界处理 | 高 |
| API 正确性 | 用对 UE 语义（单位、命名约定） | 高 |
| 工程化 | 结构清晰、可复用、防御性 | 中 |
| 性能意识 | 无冗余分配、复杂度合理 | 中 |

| # | 类型（取自失败簇预测表） | 描述 |
|---|---|---|
| 1 | 例：单位错误（cm vs m） | 具体怎么错的 |
| 2 | 例：符号错误 | 具体怎么错的 |
| 3 | 例：API 误用 | 具体怎么错的 |
